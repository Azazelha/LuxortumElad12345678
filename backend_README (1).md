# Backend (Python, FastAPI)

Размещайте здесь свои Python-сервисы, ML/LLM-скрипты, API.

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Интеграция кода

- Скопируйте Python/ML/LLM код из репозиториев Azazelha/llms, Azazelha/luxortum123 и других сюда.
- Импортируйте функции, модели и API в app/main.py или отдельные модули.
