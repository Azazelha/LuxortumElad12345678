# Frontend (Next.js, React)

Здесь размещается вся клиентская часть проекта.

## Запуск

```bash
npm install
npm run dev
```

## Интеграция

- Переносите сюда страницы, компоненты и стили из Azazelha/luxortum, Azazelha/LuxortumElad12345678, wix-cms-nextjs-template и других.
- Приводите код к единому стилю, используйте TypeScript или JavaScript.
